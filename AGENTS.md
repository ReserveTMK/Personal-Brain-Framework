# Personal-Brain Framework repository instructions

This public repository owns the reusable Personal-Brain product, installation
protocol and templates. It is not a private Personal-Brain or an RTMK knowledge
store. Never copy personal context, account selectors or secrets here.

For substantial maintenance, source-dependent questions or actions, maintainers
may consult [Agent System ways of working](https://github.com/ReserveTMK/RTMK-Agent-System/blob/main/WAYS-OF-WORKING.md)
and only relevant current methods through their authorised repository access.
Adapt methods to the task. Shared guidance grants no authority; installation is
optional. If that repository is unavailable, preserve this repository's rules
and work from its current README, INSTALL and affected source. Framework users
must not need access to the maintainer's shared repository to use this product.

Inspect Git state before edits, preserve unrelated work, re-read canonical
content before scoped changes and verify the result. Keep generic installation
instructions self-contained and compatible with existing vaults. Do not alter
installed user vaults, retire safeguards or claim host adoption from this file.
Consequential instruction or installation changes need independent review of
the exact candidate. Report tests, publication and actual adoption separately.
