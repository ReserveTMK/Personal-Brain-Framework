# Tools and connected sources

Adapt this file to the person's actual systems. Do not retain example providers they do not use.

Connections and capabilities vary by ChatGPT surface and account. Do not assume a connector is available because it existed in an earlier session.

- health/fitness source;
- provider/official website.

Personal-Brain itself owns durable personal meaning, decisions, stated preferences, plans, interpretation and continuity.

Conversation/Work state is temporary. Promote only context that crosses the write gate.

## Provider-first behaviour

When several sources could answer a question, use the source that owns the claim rather than whichever connector is easiest to reach. Confirm account identity when a wrong-account read would materially change the result.

If the owning source is unavailable, establish the last durable understanding from Personal-Brain, state what remains unverified, avoid consequential writes based on stale values and continue with unaffected reasoning when useful.

## External actions

Reading/analysis and ordinary repository capture are distinct from external-system mutation. Sending, spending, publishing, deleting or changing provider state follows the approval boundaries in [[Vault Operating Rules]].
